# MantisHash
A hybrid Rust + Python + React wallet generator based on visual entropy.

### How to run
## 🦀 Rust Core
To build Rust library:
```bash
cargo build --release
```


## 🐍 Python
Create and activate a virtual environment:
``` bash
python3 -m venv .venv
source .venv/bin/activate
pip install maturin
maturin develop
```
